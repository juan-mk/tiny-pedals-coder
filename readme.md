# Tiny Pedals Big Sound

Tienda online educativa de pedales de efectos para guitarra, inspirada en Gokko Pedals.
Proyecto final del curso de JavaScript de Coderhouse: un simulador de compra sobre el sitio original de Tiny Pedals.

En la página principal, los pedales se cargan desde un archivo JSON y se muestran dinámicamente. El usuario puede armar un carrito de compras: agregar productos, cambiar cantidades, eliminarlos o vaciar el carrito. El total se calcula automáticamente y el carrito se conserva al recargar la página.

El sitio se completa con cuatro secciones institucionales (About, Gallery, Media y Contact), con diseño responsive.
